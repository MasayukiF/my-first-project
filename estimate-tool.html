スタッフ13名ヒアリングで第1位の課題「見積PDFの手打ち作業」を減らすための社内ツールです。

3確認・修正表で中身をチェック
4本丸へ列コピー または CSV取込

2メーカー見積PDFの本文を貼り付け

見積PDFを開く → 明細の表を選択（Ctrl+Aで全選択、または明細部分だけドラッグで選択）→ Ctrl+C（コピー）→ 下の枠に Ctrl+V（貼り付け）。
全選択できないPDFは、明細の表だけを部分コピーすればOKです（むしろ余計な行が入らずキレイです）。

画像PDF（スキャン・FAX）でコピーできない時の対処

画像のPDFは文字をコピーできません。次のいずれかでテキスト化してから、上の枠に貼り付けてください：

  1. 生成AIに頼む（推奨）： claude.ai / ChatGPT / Gemini にPDFをアップロードし、こう聞きます：
    この見積書の明細表を、1行に「品名 数量 単位 単価 金額」の順でスペース区切りのテキストにして書き出してください。
    返ってきたテキストを上の枠に貼り付けて「自動で表に変換」。
  2. Adobe Acrobat の OCR機能： PDFを開いて「ファイル → テキスト認識」または「PDFを編集」で文字化 → コピー
  3. コード君に渡す： 将行さんにPDFを送って「テキスト化して」とお願いしてもOK
  4. 石田データサービスへ外注： 手書き混じり・複雑なレイアウト・大量ページのPDFは外注ルートが確実です

4本丸EXv2へ取込（列コピー または CSV）

方法A：列ごとにコピー（本丸へ縦1列で貼り付け）

ボタンを押すと、その列だけを縦1列でコピーします。本丸EXv2の対応する列に そのまま貼り付けてください。どの列も 同じ 0 行 で 揃うので、列ごとに貼っても 行ズレの心配がありません。

※ STEP1の「電気仕様：半角に変換」にチェックすると、半角カタカナでコピーされます。
方法B：CSVファイルで取り込む

取込対象（チェックの付いた行）だけをCSVに書き出します。

本丸での文字化けが心配なときは まず「Shift-JIS」を使ってください。 Excelで中身を見るだけなら「UTF-8」が確実です。
本丸EXv2 への取込手順
  1. 本丸EXv2 →「追加」→「テキスト取込」を開く
  2. 「テキスト読込設定（項目割付）」画面で、CSVファイル名の「参照」からこのツールのCSVを選択
  3. 「先頭レコードは取り込まない」にチェック（1行目は見出しのため）
  4. 項目割付：CSVの各列を本丸の項目に対応させる（下の対応表のとおり）
  5. 一度割り付けたら F1「書式登録」 で書式設定ファイルに保存 → 次回からは「参照」で読むだけ
  6. F12「読込実行」 で取込完了
取込先に注意： 取り込みは「新規の（空の）案件」で行ってください。 すでにデータが入っている案件に取り込むと、前のデータと混ざって見えることがあります。
CSVの仕様（帳票サンプル）／ 本丸の項目割付 対応表 — 石田データサービスへの依頼にも使えます
